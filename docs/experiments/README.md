# 実験ログの運用

各実験は「調査した根拠が他人にも追える」ことを目標に、次の型で記録する。数値は想像で埋めず、測定値を貼る。

```markdown
# 実験名

## 症状・目的
## 環境（OS、Node、DB、データ件数）
## 再現手順（コマンド、k6条件）
## 基準値（p50/p95/p99、エラー率、SQL計画）
## 仮説と検証計画
## 分かったこと（ログ、EXPLAIN等の根拠）
## 対策候補とトレードオフ
## 採用した変更（コミット）
## 同条件の再計測
## 残課題・次回の調査ポイント
```

重要：同じ環境・データ量・負荷条件で比較し、キャッシュウォームアップやPCの負荷なども可能な限り記録する。
