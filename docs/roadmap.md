# 12週間ロードマップ

目標：**観測 → 仮説 → 切り分け → 設計判断 → 実装 → 再計測** を繰り返し、原因調査から改善までできるようになる。想定学習時間は週4〜5時間。進捗を優先し、期間は柔軟に調整する。

## 共通の実験フロー
1. **症状**：何を遅く／不安定にしたか
2. **再現**：データ件数、負荷条件を固定
3. **観測**：基準値を測定
4. **仮説**：原因候補と検証方法を整理
5. **対策**：できるだけ一度に一つ変更
6. **再計測**：同じ条件で比較
7. **記録**：証拠、判断理由、残課題をMarkdownに残す
